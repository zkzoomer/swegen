# Refactor branch

Use for a meaningful assigned restructuring with public behavior preserved. The
captured classification precedence places feature/performance/bug-fix changes first.

- **Prompt:** state the restructuring goal, required public surface and signatures,
  and preservation contract. Do not invent arbitrary private names or a single
  reference implementation as the only acceptable repair.
- **Media:** identify a genuine structural diagram/document/specification containing
  a material requirement. Ordinary app screenshots do not make a purely internal
  refactor multimodal. If text and code already contain the whole task, report the
  assigned task unsuitable for this media-required flow.
- **Tests:** check required structural/public contract facts and meaningful behavioral
  equivalence through public interfaces. Reject no-op or cosmetic-only changes when
  meaningful restructuring is required. Avoid pinning incidental representation.
- **Unsupported:** a bug/fix recording recipe cannot manufacture an authoritative
  architecture target. Obtain the missing genuine source/specification or report the
  integration gap; do not silently turn the task into another category.

Return to [authoring](../authoring.md), [media](../media.md), and
[verification](../verification.md) at the relevant stage.
